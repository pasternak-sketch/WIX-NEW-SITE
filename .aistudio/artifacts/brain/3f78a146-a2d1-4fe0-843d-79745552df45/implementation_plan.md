# תוכנית פעולה: פרומט מקיף וקוד יחיד עצמאי (Master Prompt & Standalone Source) לאתר "שטף הנדסת סביבה"

תוכנית זו מגדירה יצירת פרומט-אב מקצועי ומלא (Master System Prompt / Spec) המכיל את כל קוד ה-HTML/CSS/JS במבנה של קובץ יחיד, שלם ועצמאי לחלוטין (Self-Contained Standalone HTML5), המיועד להזנה לכל מודל בינה מלאכותית או מחשב אחר כך שיוכל להבין, לשחזר ולהריץ את האתר בדיוק מושלם של עיצוב, תוכן, מיתוג ופונקציונליות.

***

## User Review & Critical Decisions

> [!IMPORTANT]
> **החלטות מפתח שאושרו על ידי המשתמש (Phase 1 Confirmation):**
> 1. **פורמט הפלט**: פרומט הנחיה ל-AI הכולל מפרט מפורט + קוד HTML מלא ועצמאי שלם (One-File Standalone Production Code).
> 2. **תלות בשרת**: קובץ עצמאי לחלוטין ללא תלות בשרת Node.js חיצוני, הכולל סימולציה מלאה בצד לקוח (Client-Side Simulation) עבור שליחת טפסי יצירת הקשר והחיסכון ליזמים עם משובי הצלחה וניהול שגיאות.
> 3. **שפת עיצוב נקייה ללא אימוג'ים**: שמירה קפדנית על הסרת כל האימוג'ים מכרטיסיות השירותים, טופס יצירת הקשר, כותרות האתר וחלון היזמים, תוך שימוש בתגיות קטגוריה טיפוגרפיות אלגנטיות וצבעי ירוק בוטני עמוק (#175345).
> 4. **לוגו ונגישות**: הטמעת לוגו ה-SVG המקורי המדויק באנגלית (SHETEF ENVIRONMENTAL ENGINEERING) בפינה הימנית העליונה, וכפתור נגישות קומפקטי צמוד לדופן השמאלית התחתונה של המסך.

## 1. Overview & Core Concept

- **מהות הפרויקט**: אספקת פרומט-על (Master AI Prompt) אשר יסביר לכל סוכן AI או מהנדס תוכנה במדויק את המבנה, הרכיבים, התנהגות הממשק (UX), פלטת הצבעים, הטיפוגרפיה, הנכסים הגרפיים (SVG מובנה), הנגישות המלאה (WCAG 2.1 AA) והתוכן העברי המדויק של אתר "שטף הנדסת סביבה".
- **קהל יעד ומטרה**: מחשב או מודל שפה אחר שצריך לקרוא, להבין, לנתח, להציג או לשחזר את האתר אחד-לאחד ללא צורך בהתקנת חבילות npm או שרתים נפרדים.
- **ערך מוסף**: קובץ קוד בודד שניתן להפעיל ישירות בכל דפדפן (Double-Click to Run), לשמור כ-`index.html` או לשלוח בפרומט לכל LLM מבלי לאבד אף רכיב עיצובי, לוגי או תוכני.

## 2. User Experience & Visual Design

### A. שפת העיצוב ופלטת הצבעים (Design System & Color Tokens)
- **רקע כהה מותגי (`--bg-dark`)**: `#204c44` (ירוק יער עמוק בהשראת הלוגו).
- **צבע הדגשה ראשי (`--accent-peach`)**: `#e89e54` (אפרסק/טרקוטה חם).
- **צבע הדגשה משני מוזהב (`--accent-cream`)**: `#f2de9b` (קרם מוזהב ממותג).
- **ירוק צמחיה/סייג' (`--sage`)**: `#a2cb85` (ירוק רענן בועתי).
- **כחול מים הידרולוגי (`--water`)**: `#2d9cb3` (כחול ציאן יציב).
- **ירוק בוטני אלגנטי לכותרות שירותים**: `#175345` (עמוק, נעים ויוקרתי, מחליף גוונים אפורים).
- **טיפוגרפיה**: שילוב הגופנים 'Heebo' (עבור כותרות ולוגו) ו-'Assistant' (עבור טקסט רץ וקריאות מקסימלית בעברית).

### B. רכיבי מפתח ומבנה דף (Component Breakdown)
1. **Header דביק (Sticky Header)**:
   - לוגו ה-SVG הרשמי מיושר בפינה הימנית העליונה עם תצוגת שם המותג באנגלית בלבד `SHETEF ENVIRONMENTAL ENGINEERING`.
   - תפריט ניווט ראשי עם קישורי עוגן (בית, שירותים, אודות, צור קשר).
   - כפתור הדגשה `בדיקת חיסכון ליזמים` עם נקודה אדומה פועמת (ללא אימוג'י מנורה).
   - לחצן חיוג מהיר למוקד החברה (`04-6060111`).
2. **Hero Section**:
   - כותרת מותגית גדולה, תת-כותרת טכנו-כלכלית, לחצן הנעה לפעולה ("התחילו עכשיו").
3. **About Section ("המומחיות שלנו היא ההצלחה שלך")**:
   - 18 שנות ניסיון, ראייה טכנו-כלכלית מנצחת, תמונת פרויקט הנדסי איכותית.
4. **Services Grid ("השירותים שלנו")**:
   - גריד רספונסיבי מותאם למובייל (100% רוחב) ולדסקטופ (2 עמודות).
   - תגיות קטגוריה טיפוגרפיות ללא אימוג'ים: `תשתיות וקרקע`, `תקנים ורישוי`, `שירות בלעדי ליזמים`, `היתרון ההנדסי`.
5. **Contact Section ("נשמח לשמוע מכם")**:
   - רשימת פרטי התקשרות נקייה ומקצועית (כתובת, טלפון, פקס, דוא"ל).
   - טופס פנייה הכולל ולידציה מלאה והדמיית שליחה עם משוב מעוצב.
6. **Footer**:
   - לוגו המועצה הישראלית לבנייה ירוקה וזכויות יוצרים.
7. **פופ-אפ אופטימיזציה ליזמים (Optimization Modal)**:
   - חלון קופץ עליון-שמאלי הנפתח בלחיצה בלבד (ללא פתיחה אוטומטית), מעוצב עם בולטים נקיים `✓` (ללא אימוג'ים) וטופס לידים מהיר.
8. **סרגל נגישות צמוד קיר (Accessibility Drawer - WCAG 2.1 AA)**:
   - לשונית קומפקטית מעוגלת הצמודה לדופן השמאלית התחתונה (`bottom: 24px; left: 0`).
   - סרגל כלים שלם: גדלי טקסט, ניגודיות כהה/צהובה/בהירה/שחור-לבן, הדגשת קישורים, פונט קריא, קו עזר לקריאה, קיצורי מקלדת והצהרת נגישות תקנית.

## 3. Key Product Decisions & Trade-Offs

- **החלטה 1: יצירת פרומט-על יחד עם קוד מלא (Prompt + Code)**:
  - *הגישה שנבחרה*: הפלט יכיל חלק ראשון של פרומט תיאורי מקיף (System Prompt & Architecture Overview) המנחה מודל בינה מלאכותית כיצד האתר בנוי ומעוצב, ולאחריו בלוק קוד שלם ויחיד של כל ה-HTML/CSS/JS.
  - *הסבר*: מאפשר למשתמש להעתיק את הפרומט לכל צ'אטבוט או כלי קוד (כגון ChatGPT, Claude, Gemini, Cursor) ולקבל הבנה מיידית של האתר.
- **החלטה 2: סימולציית שליחת טפסים עצמאית**:
  - *הגישה שנבחרה*: החלפת ה-`fetch('/api/contact')` התלוי בשרת בלוגיקת סימולציה מהירה ב-JS (`Promise / setTimeout`) המציגה למשתמש את משוב ההצלחה, מרוקנת את הטופס, ומדפיסה את פרטי הליד לקונסול.
  - *הסבר*: מבטיח שהקובץ עובד "מהקופסה" בכל מחשב, דפדפן או שרת סטטי ללא שגיאות 404 או צורך ב-Express.

## 5. שלבי המימוש המתוכננים

1. **ניסוח פרומט-העל (Master Prompt for External AI)**:
   - אפיון מקיף הכולל את מהות המותג, מטרת הדף, קהל היעד, מבנה ה-DOM, שפת העיצוב והחוקים הטיפוגרפיים.
2. **איחוד קוד האתר לקובץ HTML5 מלא ועצמאי (Standalone Code Block)**:
   - שילוב כל ה-CSS עם משתני ה-Root וה-Media Queries.
   - לוגו ה-SVG הרשמי מובנה ישירות ב-Header.
   - הסרת תלות בשרת Node.js והחלפת ה-Fetch בסימולציית הגשה אלגנטית ומיידית.
   - מנגנון נגישות WCAG 2.1 AA מלא ומובנה.
3. **הצגת הפרומט והקוד המלא בצורה ברורה להעתקה נוחה**.
